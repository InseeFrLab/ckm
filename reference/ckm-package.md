# ckm: Applying the Cell Key Method to Protect Tabular Data

The Cell Key Method is a method for protecting sensitive data in tabular
form by applying random keys to cells. The package implements the method
and provides tools to choose the best parameters to ensure the balance
between data utility and privacy protection. See Enderle et al. (2020)
[doi:10.1007/978-3-030-57521-2_11](https://doi.org/10.1007/978-3-030-57521-2_11)
, Jamme (2025)
[doi:10.5281/zenodo.21930561](https://doi.org/10.5281/zenodo.21930561)
and Jamme (2026)
[doi:10.13140/RG.2.2.19275.55840](https://doi.org/10.13140/RG.2.2.19275.55840)
for further details.
